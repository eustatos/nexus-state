# ART-001: Сбор материалов (Material Collection)

## 📋 Описание

Сбор всех необходимых материалов для написания статьи: скриншоты, метрики производительности, примеры кода, демонстрационные сценарии.

## 🎯 Цель

Подготовить полный набор материалов для написания качественной технической статьи.

## 🔧 Инструменты

### Для скриншотов
- **Built-in**: macOS Shift+Cmd+4/5
- **Browser**: Chrome DevTools → Command Menu → "Screenshot"
- **Extension**: Nimbus Screenshot

### Для GIF
- **Запись**: OBS Studio (бесплатно), Loom
- **Оптимизация**: Ezgif.com, Giphy.com
- **Из видео**: `ffmpeg -i input.mp4 -vf "fps=10,scale=800:-1" output.gif`

### Для диаграмм
- **Mermaid.js**: Текстовое описание → диаграмма
- **Excalidraw**: Рисованные от руки диаграммы
- **Draw.io**: Классические блок-схемы

### Для метрик
- **Chrome DevTools**: Performance tab
- **Lighthouse**: Performance score
- **Custom**: `performance.now()`, `performance.memory`
