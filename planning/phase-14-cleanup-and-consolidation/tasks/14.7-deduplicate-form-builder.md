React components for `@nexus-state/form-builder-core`.

## Usage

```typescript
import { createFormBuilder } from '@nexus-state/form-builder-core';
import { builtInComponents } from '@nexus-state/form-builder-react';

const builder = createFormBuilder();
builder.addField({ type: 'text', name: 'username' });

function FormBuilder() {
  const schema = builder.getSchema();
  
  return (
    <div>
      {schema.fields.map((field) => {
        const Component = builtInComponents[field.type];
        return <Component key={field.name} definition={field} />;
      })}
    </div>
  );
}
```

## Architecture

`@nexus-state/form-builder-react` is a thin React wrapper around `@nexus-state/form-builder-core`:

- **Core logic:** Form builder state, schema, registry, export — all in `@nexus-state/form-builder-core`
- **React components:** `builtInComponents` — React components for rendering form fields

No code duplication. React package imports from core.
