## 📝 Заметки

### Идеи
- Создать интерактивную карту экосистемы
- Добавить «Previous/Next» навигацию между частями
- Создать landing page для всей экосистемы

### Риски
- Слишком много ссылок = спам
- Ссылки на ещё не опубликованные статьи
- Изменение URL после публикации

### Решения
- Максимум 3-4 ссылки на статью
- Использовать placeholder для будущих статей
- Настроить 301 редиректы при изменении URL
