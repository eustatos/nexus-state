### 4. Исследование технических паттернов

**Изученные паттерны:**
- Snapshot (полные копии)
- Command (команды с execute/undo)
- Delta (только изменения)
- Memento (снимки + метаданные)

**Сравнение производительности:**

| Паттерн | Время сохранения | Память (100 изменений) |
|---------|-----------------|----------------------|
| Snapshot | 5-10ms | 100KB |
| Command | < 1ms | 10KB |
| Delta | 2-5ms | 5KB |
| Nexus State (Hybrid) | 2-8ms | 15-30KB |
