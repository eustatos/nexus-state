# ART-003: Написание черновика (Draft Writing)

## 📋 Описание

Написание первого полного черновика статьи на основе утверждённой структуры и собранных материалов.

pnpm add @codemirror/state @codemirror/view

**Подраздел 4.2: Атомы**
```typescript
// src/store/atoms.ts
import { atom } from '@nexus-state/core'

export const contentAtom = atom('', 'editor.content')
export const cursorAtom = atom({ line: 0, col: 0 }, 'editor.cursor')
export const statsAtom = atom(
  { characters: 0, words: 0, lines: 0 },
  'editor.stats'
)
```

**Подраздел 4.3: Editor компонент**
```typescript
import { useAtomValue, useSetAtom } from '@nexus-state/react'

function Editor() {
  const content = useAtomValue(contentAtom)
  const setContent = useSetAtom(contentAtom)
  
  return (
    <CodeMirror
      value={content}
      onChange={setContent}
      extensions={[javascript(), oneDark()]}
    />
  )
}
```

**Подраздел 4.4: Time-travel интеграция**
```typescript
import { SimpleTimeTravel } from '@nexus-state/core'

const timeTravel = new SimpleTimeTravel(store, {
  maxHistory: 100,
  autoCapture: false, // Ручное управление
  deltaSnapshots: { enabled: true }
})
```

**Подраздел 4.5: Debounce**
```typescript
function useDebounceSnapshots(delay = 1000) {
  return useMemo(() => debounce(
    (action) => timeTravel.capture(action),
    delay,
    { maxWait: 5000 }
  ), [delay])
}
```
