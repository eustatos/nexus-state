## 📝 Ключевые решения

### 1. Framework-agnostic подход

| Аспект | Решение |
|--------|---------|
| **Теория** | 100% без привязки к фреймворку |
| **Примеры** | React (70%) + Vue (20%) + Svelte (10%) |
| **Терминология** | Универсальная (без React-specific) |
| **Angular** | Не включаем (слишком сложно) |

### 2. Тон статьи

| Аспект | Решение |
|--------|---------|
| **Введение** | Без «боли/проблемы» |
| **Тон** | Спокойный, технический |
| **Статистика** | Только проверенные источники |
| **Маркетинг** | Без преувеличений |

### 3. Структура разделов

| Объём раздела | Подход | Структура |
|---------------|--------|-----------|
| **800+ слов** | Раздельный | Теория + Практика |
| **500-800 слов** | Смешанный | Концепция + Примеры |
| **<500 слов** | Смешанный | Без разделения |

**Шаблон для разделов 800+ слов:**

```markdown
### [Название раздела] (~1000 слов)

**Теория**

#### Концепция
[300-400 слов: определение, объяснение, диаграммы]

#### Когда использовать
[150-200 слов: сценарии, таблица]

#### Best Practices
[150-200 слов: рекомендации, анти-паттерны]

---

**Практика**

#### Пример 1: [Базовый]
[150-200 слов: код + минимальные комментарии]

#### Пример 2: [Продвинутый]
[150-200 слов: код + минимальные комментарии]

#### Разбор
[100-150 слов: связь с теорией, нюансы, ссылки]
```

**Разделы с разделением:**
- Часть 1: 2 из 8 разделов (25%)

- Часть 3: 6 из 8 разделов (75%)
