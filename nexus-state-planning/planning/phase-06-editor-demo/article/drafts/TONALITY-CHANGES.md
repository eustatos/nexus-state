# Отчёт о внесении изменений: Нейтральная тональность статьи

## Дата: Март 2026

## Причина изменений

Замечание от рецензента: таблица с "проблемами" библиотек может восприниматься как критика, что вызовет защитную реакцию у пользователей Redux/Zustand/Jotai и испортит впечатление от статьи.

**Обоснование:** Формулировки смещены с "недостатков" на "пожелания сообщества"

### 3. Добавлено примечание о нейтральности

**Добавлено:**

**Местоположение:** Сразу после таблицы с запросами

### 4. Переформулирован список "Типичные проблемы"

**Было:**
```markdown
**Типичные проблемы разработчиков:**

1. **State не обновляется после async операций**
   - Пример: «After dispatching async thunk, state remains unchanged»
```

**Стало:**
```markdown
**Типичные задачи разработчиков:**

1. **Отслеживание истории изменений**
   - Запрос: «Как увидеть, как состояние пришло к текущему виду?»
   - Частое решение: DevTools, логирование действий

2. **Undo/Redo**
   - Запрос: «Пользователи ожидают отмены действий, как реализовать?»
   - Частое решение: кастомная реализация или специализированные библиотеки
```

**Обоснование:** Смена фокуса с "проблем" на "задачи" и "запросы"

### 7. Таблица сравнения с альтернативами (бенчмарки)

**Было:**

| Библиотека | Time-Travel | Bundle Size | Примечание |
|------------|-------------|-------------|------------|
| **Nexus State** | ✅ Built-in | ~4KB | Delta-сжатие |
| Redux + DevTools | ✅ Plugin | ~13KB | Требуется настройка |
| Zustand | ❌ | ~1KB | Нет из коробки |
| Jotai | ❌ | ~12KB | Нет из коробки |

**Стало:**

| Библиотека | Time-Travel | Bundle Size | Примечание |
|------------|-------------|-------------|------------|
| **Nexus State** | ✅ Built-in | ~4KB | Delta-сжатие из коробки |
| Redux + DevTools | ✅ Plugin | ~13KB | Требуется настройка middleware |
| Zustand | ⚠️ Требуется реализация | ~1KB | Кастомный хук |
| Jotai | ⚠️ Требуется реализация | ~12KB | Кастомные атомы |

**Добавлено примечание:**

> **Важно:** Каждая из этих библиотек отлично решает свои задачи. Таблица показывает только наличие встроенного time-travel «из коробки». Для вашей конкретной задачи может подойти любое из решений.

**Изменения:**
- `❌` → `⚠️ Требуется реализация` (менее негативно)
- "Нет из коробки" → "Кастомный хук/атомы" (констатация факта)
- Добавлено примечание об уважении к альтернативам

### 8. Сравнительная таблица подходов (альтернативные подходы)

**Было:**

| Подход | Размер | Time-travel из коробки | Delta-сжатие | Сложность реализации |
|--------|--------|------------------------|--------------|---------------------|
| **Nexus State** | ~4KB | ✅ | ✅ | Низкая |
| Redux + middleware | ~13KB + код | ❌ | ❌ | Средняя |
| Zustand + hooks | ~1KB + код | ❌ | ❌ | Средняя |
| Jotai + атомы | ~12KB + код | ❌ | ❌ | Высокая |

**Стало:**

| Подход | Размер | Time-travel из коробки | Delta-сжатие | Сложность реализации |
|--------|--------|------------------------|--------------|---------------------|
| **Nexus State** | ~4KB | ✅ | ✅ | Низкая |
| Redux + middleware | ~13KB + код | ⚠️ Требуется middleware | ❌ | Средняя |
| Zustand + hooks | ~1KB + код | ⚠️ Требуется хук | ❌ | Средняя |
| Jotai + атомы | ~12KB + код | ⚠️ Требуется реализация | ❌ | Высокая |

**Добавлено примечание:**

> **Примечание:** В таблице указана сложность реализации *базового* time-travel без delta-сжатия. Реализация полноценного delta-сжатия (как в Nexus State) требует значительных усилий в любом случае. Каждая библиотека имеет свои преимущества для других задач.

**Изменения:**
- `❌` → `⚠️ Требуется middleware/хук/реализация` (конкретика вместо негатива)
- Добавлено примечание о преимуществах других библиотек
