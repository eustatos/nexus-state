## 🎨 Форматы ссылок

### Вариант 1: Числовые ссылки (академический)

```markdown
## Введение

По нашим данным, **62% разработчиков** тратят на отладку состояния 
**3-5 часов в неделю** [1].

...

## Источники

[1] Nexus State Research, ART-000, 2026
[2] Redux DevTools Documentation
[3] Figma Help Center
```

**Плюсы:**
- Чисто выглядит
- Академический стандарт

**Минусы:**
- Нужно поддерживать список источников
- Менее кликабельно

---

### Вариант 2: Inline ссылки (веб-стандарт)

```markdown
## Введение

По нашим данным, **62% разработчиков** тратят на отладку состояния 
**3-5 часов в неделю** ([исследование ART-000](./research/state-debug-problems.md)).

Time-travel debugging популяризирован 
[Redux DevTools](https://github.com/reduxjs/redux-devtools).
```

**Плюсы:**
- Сразу кликабельно
- Не нужен отдельный список

**Минусы:**
- Длиннее выглядит
- Может отвлекать от чтения

**Оптимально:** 1 ссылка на 150-200 слов

## ⚠️ Риски и как их избежать

### Риск 1: Ссылки ломаются

**Решение:**
- Использовать archive.org для важных ссылок
- Кэшировать копии документов
- Проверять ссылки перед публикацией

**Инструменты:**
- https://www.deadlinkchecker.com/
- https://github.com/lydell/remark-lint-no-dead-urls

---

### Риск 2: Слишком много ссылок

**Решение:**
- Приоритизировать (15-25 ключевых)
- Группировать в конце раздела
- Использовать «Читать далее» для дополнительных

---

### Риск 3: Отвлекают от чтения

**Решение:**
- Использовать сноски вместо inline
- Открывать в новой вкладке (`target="_blank"`)
- Не ссылаться на каждое утверждение
