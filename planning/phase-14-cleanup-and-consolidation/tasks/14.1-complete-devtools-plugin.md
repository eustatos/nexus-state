# Task 14.1: Complete DevTools-as-Plugin

| Meta | Value |
|------|-------|
| **Task** | Remove `DevToolsIntegration` from `StoreImpl`, make DevTools fully optional |
| **Priority** | P0 — blocks bundle size target (< 5 KB) |
| **Estimated effort** | Medium |
| **Breaking changes** | No — backward compatible via `devtools()` plugin |
| **Dependencies** | None |

## Context

**Current state (2026-07-10):**

`StoreImpl` statically imports `DevToolsIntegration` (245 lines):

```typescript
// packages/core/src/store/StoreImpl.ts (line ~72)
import { DevToolsIntegration } from './DevToolsIntegration';

class StoreImpl {
  private _devTools: DevToolsIntegration | null = null;
  
  constructor(options?: StoreOptions) {
    // ...
    if (options?.devtools) {
      this._devTools = new DevToolsIntegration(options.devtoolsConfig);
    }
  }
}
```

**Problem:** Static import adds ~0.35 KB to minimal bundle, even when DevTools is not used.

**Existing DevToolsPlugin:** `packages/core/src/plugins/devtools.ts` (300 lines) — full Redux DevTools integration. Available via `@nexus-state/core/devtools` subpath.

**Goal:** Remove `DevToolsIntegration` from core path. DevTools should only be in bundle when explicitly imported.

## Requirements

### Option A: Dynamic Import (Preferred)

Replace static import with dynamic import:

```typescript
// StoreImpl.ts
class StoreImpl {
  private _devTools: DevToolsIntegration | null = null;
  
  constructor(options?: StoreOptions) {
    // ...
    if (options?.devtools) {
      // Dynamic import — DevTools code not in minimal bundle
      import('./DevToolsIntegration').then(({ DevToolsIntegration }) => {
        this._devTools = new DevToolsIntegration(options.devtoolsConfig);
      });
    }
  }
}
```

**Pros:** Simple, minimal code change.
**Cons:** Async initialization, DevTools may miss early state changes.

### Option B: Remove from StoreImpl, Use Plugin Only

Remove `DevToolsIntegration` entirely. Users must use `devtools()` plugin:

```typescript
// Old (deprecated)
const store = createStore({ devtools: true });

// New (recommended)
import { devtools } from '@nexus-state/core/devtools';
const store = createStore({ plugins: [devtools()] });
```

**Pros:** Clean separation, zero DevTools code in core.
**Cons:** Breaking change for `options.devtools` users.

### Option C: Lazy Getter with Static Import

Keep static import but use lazy getter:

```typescript
// StoreImpl.ts
import { DevToolsIntegration } from './DevToolsIntegration';

class StoreImpl {
  private _devTools: DevToolsIntegration | null = null;
  
  getDevTools(): DevToolsIntegration | null {
    if (!this._devTools && this.options?.devtools) {
      this._devTools = new DevToolsIntegration(this.options.devtoolsConfig);
    }
    return this._devTools;
  }
}
```

**Pros:** Backward compatible, lazy creation.
**Cons:** DevTools code still in bundle (static import).

### 2. Deprecate `options.devtools`

```typescript
// store.ts
export function createStore(options?: StoreOptions | Plugin[]): Store {
  if (Array.isArray(options)) {
    // Legacy: createStore([plugin1, plugin2])
    return new StoreImpl({ plugins: options });
  }
  
  if (options?.devtools) {
    console.warn(
      'options.devtools is deprecated. Use devtools() plugin instead:\n' +
      'import { devtools } from "@nexus-state/core/devtools";\n' +
      'createStore({ plugins: [devtools()] })'
    );
    // Auto-apply devtools plugin for backward compatibility
    const devtoolsPlugin = require('@nexus-state/core/devtools').devtools();
    options.plugins = [...(options.plugins || []), devtoolsPlugin];
  }
  
  return new StoreImpl(options);
}
```
