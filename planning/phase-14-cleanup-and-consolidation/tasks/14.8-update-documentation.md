# Migration Guide

This guide covers breaking changes across all versions.

## v1.0.0 (Phase 14)

### Removed: Global Singletons

**`batcher` removed:**

```diff
- import { batcher } from '@nexus-state/core/batching';
- batcher.batch(() => { ... });
+ import { batch } from '@nexus-state/core/batching';
+ batch(() => { ... });
```

**`globalActionTracker` removed:**

```diff
- import { globalActionTracker } from '@nexus-state/core/utils';
- globalActionTracker.track('action', payload);
+ import { ActionTracker } from '@nexus-state/core/utils';
+ const tracker = new ActionTracker();
+ tracker.track('action', payload);
```

### Deprecated: `options.devtools`

```diff
- const store = createStore({ devtools: true });
+ import { devtools } from '@nexus-state/core/devtools';
+ const store = createStore({ plugins: [devtools()] });
```

`options.devtools` still works but shows deprecation warning. Will be removed in v1.1.0.

### Package Consolidation

**Old packages (deprecated, will be removed in v1.1.0):**

```diff
- import { asyncAtom } from '@nexus-state/async';
+ import { asyncAtom } from '@nexus-state/extras/async';

- import { atomFamily } from '@nexus-state/family';
+ import { atomFamily } from '@nexus-state/extras/family';

- import { immerAtom } from '@nexus-state/immer';
+ import { immerAtom } from '@nexus-state/extras/immer';

- import { persistAtom } from '@nexus-state/persist';
+ import { persistAtom } from '@nexus-state/extras/persist';

- import { middleware } from '@nexus-state/middleware';
+ import { middleware } from '@nexus-state/extras/middleware';

- import { workerAtom } from '@nexus-state/web-worker';
+ import { workerAtom } from '@nexus-state/extras/web-worker';
```

Old packages re-export from `@nexus-state/extras` for backward compatibility.

### Form Package: React Hooks Moved to Subpath

```diff
- import { useForm } from '@nexus-state/form';
+ import { useForm } from '@nexus-state/form/react';
```

Core API (`createForm`) unchanged. React hooks now in `./react` subpath.

**Why:** Form package was hard-depending on React, forcing React on Vue/Svelte users.

## v0.2.x (Phase 12 + 13)

### Removed: Global `atomRegistry`

Atoms are now scoped to each store. No global registry.

```diff
- import { createIsolatedRegistry } from '@nexus-state/core';
- const isolated = createIsolatedRegistry();
+ // Every store is isolated by default
+ const store1 = createStore();
+ const store2 = createStore(); // completely independent
```

### Removed: `AtomStateManager`

Internal refactoring. No public API change.

### Removed: Dead Code

- `enhanced-store.ts` — deleted
- `SignalBasedReactive` — deleted
- `reactive/config.ts` — deleted
```

### 3. Update Main README.md

```markdown
# @nexus-state/core

Minimal, tree-shakeable state management library.

## Features

- **Minimal bundle:** < 5 KB gzipped (atom + createStore)
- **Tree-shakeable:** Optional features (DevTools, batching, reactive) via subpath exports
- **Zero global singletons:** SSR-safe by default
- **Computed atoms:** Automatic dependency tracking
- **Plugin system:** Extensible with middleware

## Installation

```bash
npm install @nexus-state/core
```

## Quick Start

```typescript
import { atom, createStore } from '@nexus-state/core';

const countAtom = atom(0);
const doubleAtom = atom((get) => get(countAtom) * 2);

const store = createStore();

store.set(countAtom, 5);
console.log(store.get(doubleAtom)); // 10
```

## Optional Features

### Batching

```typescript
import { batch } from '@nexus-state/core/batching';

batch(() => {
  store.set(atom1, 1);
  store.set(atom2, 2);
  // Only one notification
});
```

### DevTools

```typescript
import { devtools } from '@nexus-state/core/devtools';

const store = createStore({ plugins: [devtools()] });
```

### Reactive Values

```typescript
import { createReactiveValue } from '@nexus-state/core/reactive';

const reactive = createReactiveValue(store, atom);
```

## Ecosystem

| Package | Description |
|---------|-------------|
| [`@nexus-state/react`](./packages/react/) | React hooks |
| [`@nexus-state/vue`](./packages/vue/) | Vue composables |

| [`@nexus-state/extras`](./packages/extras/) | Async, family, immer, persist, middleware, web-worker |

| [`@nexus-state/query`](./packages/query/) | Data fetching and caching |

| [`@nexus-state/undo-redo`](./packages/undo-redo/) | Undo/redo |

## Migration

See [MIGRATION.md](./MIGRATION.md) for breaking changes and migration guides.

### 4. Update CHANGELOG.md

```markdown
# Changelog

All notable changes to this project will be documented in this file.

## [1.0.0] - 2026-07-10

### Breaking Changes

- **Removed `batcher` global singleton** — use `batch()` function instead
- **Removed `globalActionTracker` global singleton** — use per-instance `ActionTracker` instead
- **Consolidated micro-packages** — `@nexus-state/async`, `family`, `immer`, `persist`, `middleware`, `web-worker` merged into `@nexus-state/extras` (old packages deprecated, will be removed in v1.1.0)
- **Form package: React hooks moved to subpath** — `import { useForm } from '@nexus-state/form/react'` instead of `@nexus-state/form`

### Features

- **New package: `@nexus-state/extras`** — consolidated async, family, immer, persist, middleware, web-worker with subpath exports
- **Form package is now framework-agnostic** — no React dependency in main entry, React hooks in `./react` subpath

### Improvements

- **Minimal bundle reduced to < 5 KB** — removed `DevToolsIntegration` from core path
- **`DevToolsIntegration` deprecated** — use `devtools()` plugin from `@nexus-state/core/devtools`
- **`form-builder-react` deduplicated** — imports from `form-builder-core`, no code duplication

### Documentation

- Updated `MIGRATION.md` with v1.0.0 breaking changes
- Updated main `README.md` with new package structure
- Added time-travel decision document

## [0.2.1] - 2026-06-05

### Features

- **ScopedRegistry** — unified atom registry per store (Phase 12)
- **Lazy subsystem initialization** — optional subsystems created on demand (Phase 13)
- **Subpath exports** — `@nexus-state/core/batching`, `./debug`, `./devtools`, `./reactive`, `./utils`
- **PluginSystem O(1) optimization** — early return when no plugins

### Improvements

- Removed `AtomStateManager` — data now in `ScopedRegistry` only
- Removed dead code: `enhanced-store.ts`, `SignalBasedReactive.ts`, `reactive/config.ts`
- Removed global `atomRegistry` — atoms scoped to stores

### Breaking Changes

- **Removed `createIsolatedRegistry()`** — every store is isolated by default
```
