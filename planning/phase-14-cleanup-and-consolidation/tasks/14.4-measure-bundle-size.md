## Comparison with Other Libraries

| Library | Minimal Bundle | Features |
|---------|----------------|----------|
| **@nexus-state/core** | **4.8 KB** | atom, store, computed, subscriptions |
| Jotai | ~3.5 KB | atom, store, computed |
| Zustand | ~1.2 KB | store, subscriptions |
| Valtio | ~2.8 KB | proxy-based store |
| Recoil | ~14 KB | atom, store, computed, selectors |

**Note:** @nexus-state/core includes more features than Jotai/Zustand (computed atoms, dependency tracking, notification system), so slightly larger bundle is expected.

## Recommendations

1. **Current size is acceptable:** 4.8 KB gzipped is competitive with Jotai (3.5 KB) given additional features.
2. **Further optimization possible:** Could reduce to ~4 KB by making `DependencyTracker` optional, but would break computed atoms.
3. **Monitor in CI:** Add bundle size check to CI pipeline to prevent regression.

### 5. Add CI Check (Optional)

```yaml
# .github/workflows/bundle-size.yml
name: Bundle Size Check

on: [pull_request]

jobs:
  bundle-size:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v3
      - uses: actions/setup-node@v3
        with:
          node-version: '20'
      
      - run: pnpm install
      - run: pnpm --filter @nexus-state/core build
      - run: pnpm --filter @nexus-state/core bundle:measure
      
      - name: Check minimal bundle size
        run: |
          SIZE=$(cat packages/core/bundle-report.json | jq '.minimal.gzip')
          if (( $(echo "$SIZE > 5000" | bc -l) )); then
            echo "❌ Minimal bundle exceeds 5 KB: $SIZE bytes"
            exit 1
          else
            echo "✅ Minimal bundle: $SIZE bytes"
          fi
```
