## 📊 Позиционирование

### Традиционное

```
Time-Travel = Инструмент отладки для разработчиков
```

**Где:**
- Redux DevTools
- Отладка в IDE
- Логирование действий

**Аудитория:** Разработчики

---

### Новое (наша позиция)

```
Time-Travel = Пользовательская функциональность
              (как в Figma, Google Docs)
```

**Где:**
- Figma (Version History)
- Google Docs (View → Version History)
- Photoshop (History Panel)
- **Формы** (наша цель)

**Аудитория:** Конечные пользователи

---

## 🔄 Аналогия: Формы ≈ Редакторы

| Аспект | Текстовый редактор | Форма | Общее |
|--------|-------------------|-------|-------|
| **Ввод данных** | Пользователь печатает текст | Пользователь заполняет поля | ✅ |
| **Ошибки** | Удалил не то | Очистил форму случайно | ✅ |
| **Эксперименты** | «А что если переписать...» | «А что если изменить...» | ✅ |
| **Ожидания** | Ctrl+Z работает | Ctrl+Z должен работать | ✅ |

**Вывод:** Пользователи форм **ожидают** того же поведения, что и в редакторах.

```markdown
Но есть и другая сторона истории.

### Time-Travel: от отладки к пользовательской функциональности

Традиционно time-travel ассоциируется с **инструментом отладки** 
для разработчиков — как Redux DevTools. Однако пользователи 
современных приложений ожидают гораздо большего:

| Приложение | Ожидание пользователя |
|------------|----------------------|
| Текстовый редактор | Ctrl+Z работает всегда |
| Графический редактор | История версий доступна |
| **Форма** | **?** |

Мы считаем, что **формы — это следующий рубеж**.
```

**Эффект:**
- Явно заявлена позиция
- Показана аналогия между редакторами и формами
- Nexus State позиционируется как user feature

## 📚 Источники для новой позиции

### 1. Формы ≈ Редакторы

| Источник | Поддержка |
|----------|-----------|
| [Nielsen Norman Group](https://nngroup.com/articles/undo-redo/) | «Undo is one of the most requested features in any application where users input data» |
| [Windows UX Guidelines](https://learn.microsoft.com/en-us/windows/win32/uxguide/inter-undo) | «Provide undo for any command that changes the state of the application» |
| [macOS HIG](https://developer.apple.com/design/human-interface-guidelines/undo-and-redo) | «Support undo for all user actions that change your app's state» |

### 2. Продукты с user-facing time-travel

| Продукт | Реализация |
|---------|------------|
| Figma | Version History с названиями действий |
| Google Docs | Version History + Suggestion Mode |
| Photoshop | History Panel (1000 шагов) |
| VS Code | Timeline (local history) |
| Airtable | Cell-level undo/redo |
| Notion | Page version history |
