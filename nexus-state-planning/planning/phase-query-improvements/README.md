# @nexus-state/query: План улучшений

## Обзор

Эта фаза содержит задачи по улучшению эргономики и типизации библиотеки `@nexus-state/query` для соответствия ожиданиям разработчиков, знакомых с TanStack Query.

## Проблемы

1. **Отсутствие автоматического вывода типов** — требуется явная типизация `TVariables`
2. **Бойлерплейт с AxiosResponse** — ручное извлечение данных в каждой мутации
3. **Недостаточная документация** — нет руководств по типизации

## Дорожная карта

### Этап 1: Базовые улучшения (Задачи 001-003)

**Цель:** Устранить основные боли пользователей

1. **Задача 001** — Автоматический вывод `TVariables`
   - Устраняет необходимость явной типизации
   - Критично для эргономики

2. **Задача 002** — Axios хелперы
   - Упрощает работу с AxiosResponse
   - Уменьшает бойлерплейт

3. **Задача 003** — Документация
   - Руководство по типизации
   - Примеры для всех сценариев

**Оценка:** 8-12 часов

### Этап 2: Продвинутые улучшения (Задача 004)

**Цель:** Полная совместимость с ожиданиями от библиотеки

1. **Задача 004** — Перегрузки функций
   - Поддержка обоих подходов (автоматический + явный)
   - Обратная совместимость

**Оценка:** 6-8 часов
