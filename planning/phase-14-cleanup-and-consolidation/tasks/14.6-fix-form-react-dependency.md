| Meta | Value |

| **Task** | Make `@nexus-state/form` framework-agnostic |

| **Estimated effort** | Medium |

## Context

**Current state (2026-07-10):**

```json
// packages/form/package.json
{
  "dependencies": {
    "@nexus-state/react": "workspace:*"
  },
  "peerDependencies": {
    "react": "^18.0.0 || ^19.0.0"
  }
}
```

**Problem:** Vue/Svelte users of `@nexus-state/form` must install React. Form package is not framework-agnostic despite claims.

**Current exports:**

```typescript
// packages/form/src/index.ts
export { useForm, useFormState, useField } from './hooks/useForm';
export { createForm, type FormConfig } from './createForm';
export type { Form, Field, ValidationRule } from './types';
```

**React hooks:** `useForm`, `useFormState`, `useField` are React-specific (use `useSyncExternalStore`, `useCallback`, etc.).

### 5. Update React Hooks

```typescript
// packages/form/src/hooks/useForm.ts
import { useSyncExternalStore, useCallback } from 'react';
import { createForm, type FormConfig, type Form } from '../createForm';

export function useForm<T>(config: FormConfig<T>): UseFormReturn<T> {
  const form = useMemo(() => createForm(config), [config]);
  
  const state = useSyncExternalStore(
    form.subscribe,
    form.getState,
    form.getState
  );
  
  const handleSubmit = useCallback(
    (onSubmit: (values: T) => void) => {
      return (event?: React.FormEvent) => {
        event?.preventDefault();
        form.validate().then((isValid) => {
          if (isValid) onSubmit(form.getValues());
        });
      };
    },
    [form]
  );
  
  return {
    state,
    handleSubmit,
    getFieldProps: form.getFieldProps,
    setFieldValue: form.setFieldValue,
    validate: form.validate,
  };
}
```

# @nexus-state/form

Type-safe form management for `@nexus-state/core`. Framework-agnostic core with optional React hooks.

## Installation

```bash
npm install @nexus-state/form
```

## Usage

### Framework-Agnostic Core

```typescript
import { createForm } from '@nexus-state/form';

const form = createForm({
  initialValues: { name: '', email: '' },
  validate: (values) => ({
    name: values.name ? undefined : 'Required',
    email: values.email.includes('@') ? undefined : 'Invalid email',
  }),
});

// Subscribe to state changes
form.subscribe((state) => {
  console.log('Form state:', state);
});

// Update field
form.setFieldValue('name', 'Alice');

// Validate
const isValid = await form.validate();

// Get values
const values = form.getValues();
```

### React Hooks

```typescript
import { useForm } from '@nexus-state/form/react';

function ContactForm() {
  const { state, handleSubmit, getFieldProps } = useForm({
    initialValues: { name: '', email: '' },
    validate: (values) => ({
      name: values.name ? undefined : 'Required',
    }),
  });
  
  return (
    <form onSubmit={handleSubmit((values) => console.log(values))}>
      <input {...getFieldProps('name')} />
      {state.errors.name && <span>{state.errors.name}</span>}
      <button type="submit">Submit</button>
    </form>
  );
}
```

**Before (v0.2.x):**
