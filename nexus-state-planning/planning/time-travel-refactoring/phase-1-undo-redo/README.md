# Фаза 1: Создание @nexus-state/undo-redo

## Цель
Создать лёгкий пакет (~150 KB) для базового user-facing undo/redo функционала.

## Оценка времени
1-2 дня

- [ ] Создать директорию `packages/undo-redo`
- [ ] Создать `package.json` с зависимостями
- [ ] Создать `tsconfig.json` для компиляции
- [ ] Создать базовую структуру директорий `src/`
- [ ] Настроить build скрипты
