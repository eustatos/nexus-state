### 3. Углублён анализ trade-offs для массивов

**Было:**

| Сценарий | Эффективность |
|----------|---------------|
| Изменение 1 элемента в массиве 1000 | ~50% экономия ⚠️ |

**Стало:**

| Подход | Размер дельты | Восстановление | Когда использовать |
|--------|---------------|----------------|-------------------|
| JSON diff | ~95% оригинала | O(N) | Маленькие массивы (<100) |
| Keyed array diff | ~5% оригинала | O(1) | Большие массивы с ID |
| Полный снимок | 100% | O(1) | Когда важна скорость |

**Добавлен пример кода:**

```typescript
// ❌ JSON diff сравнивает содержимое
const oldArray = [{ id: 1, text: 'a' }, { id: 2, text: 'b' }, ...]
const newArray = [{ id: 1, text: 'a' }, { id: 2, text: 'B' }, ...]
// Дельта: почти весь массив

// ✅ Keyed diff сравнивает по ID
const delta = { updated: [{ id: 2, text: 'B' }] }
// Дельта: только изменённый объект
```

**Прирост:** ~150 слов, но значительно глубже понимание
