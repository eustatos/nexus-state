# Task 14.5: Consolidate Micro-Packages

| Meta | Value |
|------|-------|
| **Task** | Merge 6 single-file packages into `@nexus-state/extras` |
| **Priority** | P1 — reduces package management overhead |
| **Estimated effort** | Large |
| **Breaking changes** | **Yes** — requires migration (temporary re-exports) |
| **Dependencies** | None |

## Context

**Current state (2026-07-10):**

| Package | Lines | Files | Justification |
|---------|-------|-------|---------------|
| `@nexus-state/async` | ~80 | 1 | Weak — helper function |
| `@nexus-state/family` | ~50 | 1 | Weak — trivial utility |
| `@nexus-state/immer` | ~70 | 1 | Weak — single function |
| `@nexus-state/persist` | ~70 | 1 | Weak — single plugin |
| `@nexus-state/middleware` | ~180 | 1 | Moderate — small plugin |
| `@nexus-state/web-worker` | ~100 | 1 | Moderate — separate concept |

**Problem:** Each package has its own `package.json`, README, tests, build config. Maintenance burden. Confusing for users.

**Keep separate:**
- `@nexus-state/svelte` (~20 lines) — framework isolation
- `@nexus-state/vue` (~25 lines) — framework isolation

**Why framework packages stay separate:** Different peer dependencies, different release cycles, users only install one.

## Requirements

### 1. Create `@nexus-state/extras` Package

```bash
mkdir -p packages/extras/src
```

**Directory structure:**

```
packages/extras/
├── package.json
├── README.md
├── tsconfig.json
├── src/
│   ├── index.ts              ← re-exports all subpaths
│   ├── async.ts              ← from packages/async
│   ├── family.ts             ← from packages/family
│   ├── immer.ts              ← from packages/immer
│   ├── persist.ts            ← from packages/persist
│   ├── middleware.ts         ← from packages/middleware

### 6. Update Documentation

**`packages/extras/README.md`:**

```markdown
# @nexus-state/extras

Collection of optional plugins and utilities for `@nexus-state/core`.

## Installation

```bash
npm install @nexus-state/extras
```

## Usage

### Async Atom

```typescript
import { asyncAtom } from '@nexus-state/extras/async';

const userAtom = asyncAtom(async () => {
  const response = await fetch('/api/user');
  return response.json();
});
```

### Atom Family

```typescript
import { atomFamily } from '@nexus-state/extras/family';

const todoAtomFamily = atomFamily((id: number) => {
  return atom({ id, completed: false });
});
```

### Immer Integration

```typescript
import { immerAtom } from '@nexus-state/extras/immer';

const stateAtom = immerAtom({ count: 0 });

store.set(stateAtom, (draft) => {
  draft.count++;
});
```

### Persistence

```typescript
import { persistAtom } from '@nexus-state/extras/persist';

const settingsAtom = persistAtom('settings', { theme: 'dark' });
```

### Middleware

```typescript
import { middleware } from '@nexus-state/extras/middleware';

const logger = middleware({
  beforeSet: (atom, value) => console.log('Setting', atom.name, value),
  afterSet: (atom, value) => console.log('Set', atom.name, value),
});

const store = createStore({ plugins: [logger] });
```

### Web Worker

```typescript
import { workerAtom } from '@nexus-state/extras/web-worker';

const computedAtom = workerAtom({
  worker: new Worker('./heavy-computation.js'),
  initialValue: 0,
});
```
