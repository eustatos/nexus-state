# План рефакторинга @nexus-state/core

## Принципы рефакторинга

### Основные правила
1. **SPR (Small Pull Requests)** — каждый PR ≤ 200 строк изменений
2. **TDD** — сначала characterization tests, потом рефакторинг
3. **Непрерывная интеграция** — сборка и тесты после каждого шага
4. **strict: true** — никаких `any` в новом коде

### Чеклист перед рефакторингом
- [ ] Созданы characterization tests для текущего поведения
- [ ] Зафиксировано текущее покрытие
- [ ] План рефакторинга разбит на шаги ≤ 200 строк
- [ ] Определены критерии приёмки

### Чеклист после рефакторинга
- [ ] Все тесты проходят
- [ ] `pnpm build` — успешно
- [ ] `pnpm lint` — без ошибок
- [ ] `pnpm tsc --noEmit` — без ошибок
- [ ] Покрытие ≥ 90% для изменённых файлов
