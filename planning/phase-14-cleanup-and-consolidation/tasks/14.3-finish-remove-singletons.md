## Requirements

### 1. Remove `batcher` Export

```diff
  // packages/core/src/batching.ts
- /**
-  * @deprecated Use per-store Batcher instead. Global state is SSR-unsafe and causes test pollution.
-  */
- export const batcher = standaloneBatcher;
  
  // Keep standaloneBatcher for internal use (batch() function)
  const standaloneBatcher = new Batcher();
  
  export function batch(fn: () => void): void {
    standaloneBatcher.batch(fn);
  }
  
  export function isBatching(): boolean {
    return standaloneBatcher.isBatching();
  }
```

**Note:** `standaloneBatcher` still exists internally for `batch()` function, but is not exported.

### 5. Update MIGRATION.md

```markdown
## Migration Guide: v0.2.x → v1.0.0

### Removed: `batcher` Global Singleton

**Before (v0.2.x):**
```typescript
import { batcher } from '@nexus-state/core/batching';

batcher.batch(() => {
  store.set(atom1, 1);
  store.set(atom2, 2);
});
```

**After (v1.0.0):**
```typescript
import { batch } from '@nexus-state/core/batching';

batch(() => {
  store.set(atom1, 1);
  store.set(atom2, 2);
});
```

**Why:** Global `batcher` was SSR-unsafe and caused test pollution. Use `batch()` function instead.

### Removed: `globalActionTracker` Global Singleton

**Before (v0.2.x):**
```typescript
import { globalActionTracker } from '@nexus-state/core/utils';

globalActionTracker.track('user:login', { userId: 123 });
```

**After (v1.0.0):**
```typescript
import { ActionTracker } from '@nexus-state/core/utils';

const tracker = new ActionTracker();
tracker.track('user:login', { userId: 123 });
```

**Why:** Global `globalActionTracker` was SSR-unsafe. Use per-instance `ActionTracker` instead.
```
