## 📝 Требования к примерам

### Форматирование

```typescript
// ✅ Хорошо: с комментариями и контекстом
import { atom, createStore } from '@nexus-state/core'

// Создаём атом с начальным значением 0
const countAtom = atom(0, 'count')

// Создаём store
const store = createStore()

// Получаем значение
console.log(store.get(countAtom)) // 0

// Устанавливаем новое значение
store.set(countAtom, 5)
console.log(store.get(countAtom)) // 5
```

```typescript
// ❌ Плохо: без контекста
const a = atom(0)
const s = createStore()
s.set(a, 5)
```

### Комментарии

**Правила:**
1. Объяснять **почему**, а не **что**
2. Избегать очевидных комментариев
3. Использовать JSDoc для функций

```typescript
// ✅ Хорошо
// Debounce предотвращает создание слишком частых снимков
const debouncedCapture = debounce(capture, 1000)

// ❌ Плохо
// Вызываем функцию debounce
const debouncedCapture = debounce(capture, 1000)
```

### Именование

```typescript
// ✅ Хорошо
const contentAtom = atom('', 'editor.content')
const timeTravel = new SimpleTimeTravel(store, config)

// ❌ Плохо
const a = atom(0)
const tt = new SimpleTimeTravel(s, c)
```
